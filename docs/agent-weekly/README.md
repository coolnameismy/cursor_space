# AI Agent 周报索引

由项目 skill [weekly-agentic-digest](../../.cursor/skills/weekly-agentic-digest/SKILL.md) 生成。默认覆盖上一个完整 ISO 周。

## 使用

在 Agent 对话中说「抓一下上周的 agentic 文章」或执行 `/weekly-agentic-digest`。

需要每周自动跑时，配合 `/loop`（间隔 7 天）或 `/automate`（建议 cron：`0 14 * * 1`，周一 14:00 UTC）。
